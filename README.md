# Smart News Bot

Telegram-бот, который автоматически следит за новостями на Habr и отправляет последние новости подписчикам в Telegram.

## Что умеет бот

- Парсит главную страницу Habr и находит последнюю новость
- Сохраняет последнюю новость в CSV-файл
- Проверяет, есть ли новая публикация, и не дублирует старые новости
- Отправляет актуальные новости подписчикам по расписанию
- Поддерживает команды для управления подпиской и получения новостей

## Основные команды

- /start — приветствие и краткая информация о боте
- /news — показать последнюю новость
- /subscribe — подписаться на рассылку новостей
- /unsubscribe — отписаться от рассылки

## Технологии

- Python 3.11
- aiogram 3
- SQLite
- BeautifulSoup
- pandas
- requests

## Подготовка

1. Убедитесь, что у вас установлен Python 3.11+
2. Создайте файл .env в корне проекта
3. Добавьте токен вашего Telegram-бота:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

## Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск локально

```bash
python main.py
```

## Запуск через Docker

```bash
docker compose up --build
```

## Как это работает

- При запуске бота создаётся таблица подписчиков в SQLite
- В фоне запускается цикл, который периодически проверяет Habr
- Если появляется новая новость, бот отправляет её всем подписчикам
- Пользователь может подписаться или отписаться через команды Telegram
